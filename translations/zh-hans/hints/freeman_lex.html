要实现这个想法，首先要对列表进行排序。使用sort() list 方法进行就地排序。 

items.sort()

如何获取列表中每三个相邻元素？

使用for loop ，遍历列表中的元素，从range() 函数中获取它们的索引。 

for i in range(...):
    ...

由于要在循环内处理相邻的三个元素，为了避免产生超出列表的索引，需要遍历的元素不是列表的最末端，而是少两个元素。

如何做到这一点呢？您需要使用内置的len() 函数找出列表的长度，然后减去2 。将结果作为range() 的参数。 

for i in range(len(items) - 2):
    ...

如何获取列表中相邻三个元素的值？

为了使你的解决方案更易读，让我们创建三个变量first、second 和third。使用unpacking 和slicing 将列表中相邻三个元素的值赋值给变量。 

f, s, t = items[i: i + 3]

如何进行差值检查？

很简单。使用if statement 和not equal (!=) 操作符，比较两对变量之间的差异。 

if t - s!= s - f:
    ...

我们的列表是按升序排序的（三个元素中第一个元素最小，第三个元素最大），因此两个差值都是正数。

如何找到缺失的元素？

如果前一个条件是True （找到了 "缺口"），则需要从t 中减去差值s - f 。 

t - (s - f)

那么，为什么它能起作用呢？例如，您有一个排序列表[1, 2, 4] 。如果从4 中减去 "正常 "步骤2 - 1 == 1 ，就会得到一个正确答案4 - 1 == 3 。

但是，如果 "间隙 "在第二个元素和第一个元素之间，它也同样有效！您有一个列表[1, 3, 4] 。如果做必要的减法 -4 - (3 - 1) == 4 - 2 == 2 ，您又会得到一个正确的答案！

那么，我的最终解决方案应该是怎样的呢？

您只需将代码封装成函数表达式，连接上述所有语句，并返回最后一个表达式的减法结果。

这就是整个解决方案：

def missing_number(items: list[int]) -> int:

    items.sort()
    for i in range(len(items) - 2):
        f, s, t = items[i: i + 3]
        if t - s!= s - f:
            return t - (s - f)

在这个解决方案中，你要找到步长并遍历正确的级数。如果序列中的某个元素不在初始列表中，它就是答案。 

def missing_number(items: list[int]) -> int:

    first, *_, last = sorted(items)
    step = (last - first) // len(items)
    for i in range(first+step, last, step):
        if i not in items:
            return i

可以用公式计算某些递进元素的总和。因此，这个总和与初始列表中元素总和的差值就是缺失的元素。 

def missing_number(items: List[int]) -> int:   

    first, *_, last = sorted(items)
    total = (first + last) * (len(items) + 1) // 2

    return total - sum(items)

💡 Pour la solution que je vous propose, l'idée est la suivante. Puisque la différence entre deux nombres adjacents dans la progression arithmétique est constante, vous devez vérifier tous les trois éléments de la liste initiale triée et trouver l'"écart" - lorsque les différences entre les éléments de deux paires adjacentes dans un triplet ne sont pas égales.

D'accord, par quoi dois-je commencer?

Pour réaliser l'idée, votre liste doit être triée. Effectuez un tri sur place à l'aide de la méthode sort() list. 

items.sort()

Comment obtenir les trois éléments adjacents de la liste?

En utilisant for loop, itérer sur les éléments de la liste, en prenant leurs index dans la fonction range(). 

for i in range(...):
    ...

Comme vous allez travailler avec trois éléments adjacents à l'intérieur d'une boucle et afin d'éviter de générer des index hors de la liste, vous devez itérer non pas jusqu'à la fin de la liste, mais deux éléments plus bas.

Comment procéder? Vous devez trouver la longueur de la liste à l'aide de la fonction intégrée len() et en soustraire 2. Utilisez le résultat comme argument de range(). 

for i in range(len(items) - 2):
    ...

Comment obtenir les valeurs de trois éléments adjacents de la liste?

Pour rendre votre solution plus lisible, créons trois variables: first, second et third. Utilisez unpacking et slicing pour affecter aux variables les valeurs de trois éléments adjacents de la liste. 

f, s, t = items[i: i + 3]

Comment effectuer exactement la vérification des différences?

Eh bien, c'est facile. En utilisant les opérateurs if statement et not equal (!=), comparez les différences entre deux paires de variables. 

if t - s!= s - f:
    ...

Notre liste est triée par ordre croissant (le premier élément parmi trois est le plus petit, le troisième - le plus grand), de sorte que les deux différences sont positives.

Comment trouver l'élément manquant?

Si la condition précédente est True (l'"écart" est trouvé), vous devez soustraire la différence entre s - f et t. 

t - (s - f)

Alors, pourquoi cela fonctionne-t-il? Par exemple, vous avez une liste triée [1, 2, 4]. Si vous soustrayez de 4 l'étape "normale" de cette progression 2 - 1 == 1, vous obtenez une réponse correcte 4 - 1 == 3.

Mais cela fonctionne également si l'"écart" se situe entre le deuxième et le premier élément! Vous avez une liste [1, 3, 4]. Si vous effectuez les soustractions nécessaires - 4 - (3 - 1) == 4 - 2 == 2, vous obtenez à nouveau une réponse correcte!

Alors, à quoi devrait ressembler ma solution finale?

Il vous suffit d'envelopper votre code dans une expression de fonction, de joindre toutes les déclarations ci-dessus et de renvoyer le résultat de la dernière expression avec les soustractions.

Voici la solution complète:

def missing_number(items: list[int]) -> int:

    items.sort()
    for i in range(len(items) - 2):
        f, s, t = items[i: i + 3]
        if t - s!= s - f:
            return t - (s - f)

Bien sûr, prenez-le!

Dans cette solution, vous trouvez l'étape et itérez sur la progression correcte. Si un élément de la progression n'est pas présent dans la liste initiale - c'est la réponse. 

def missing_number(items: list[int]) -> int:

    first, *_, last = sorted(items)
    step = (last - first) // len(items)
    for i in range(first+step, last, step):
        if i not in items:
            return i

La somme d'un certain nombre d'éléments de la progression peut être comptée par la formule. La différence entre cette somme et la somme des éléments de la liste initiale est l'élément manquant. 

def missing_number(items: List[int]) -> int:   

    first, *_, last = sorted(items)
    total = (first + last) * (len(items) + 1) // 2

    return total - sum(items)
